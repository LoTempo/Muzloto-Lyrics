Karaoke Player

Простой караоке-плеер, который работает прямо в браузере.

Программа позволяет загрузить аудиофайл и текст песни, после чего отображает строки текста с плавной подсветкой во время воспроизведения.

Возможности
- загрузка аудио;
- загрузка текста песни в формате TXT или LRC;
- автоматическое создание караоке-разметки из обычного TXT-файла;
- плавная подсветка текущей строки;
- автоматическая прокрутка текста;
- переход к нужному моменту песни по клику на строку;
- адаптивный интерфейс для компьютера и телефона.

Как запустить
- Скачайте проект.
- Откройте файл index.html в браузере.
- Загрузите аудиофайл.
- Загрузите TXT или LRC-файл с текстом.

Поддерживаемые файлы

Аудио:
- MP3;
- M4A;
- WAV;
- другие форматы, которые поддерживает браузер.

Текст:
- TXT;
- LRC.

Как работает TXT
- Если загружен обычный TXT-файл без временных меток, программа автоматически распределяет строки по длительности аудио.
- Для более точной синхронизации лучше использовать LRC-файл.
